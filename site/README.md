# Website

The site is generated by `newsbot/publish/site.py` into `site/public/` (gitignored) and deployed to
Cloudflare Pages or GitHub Pages. Every post gets a sourced page, plus:

- `/corrections/` the public corrections log (`python -m newsbot corrections`)
- a latest-posts hub (link in every bio) and the Privacy Policy page Meta requires for the app

Not built yet: the hub page, the privacy policy page, and the deploy workflow.
